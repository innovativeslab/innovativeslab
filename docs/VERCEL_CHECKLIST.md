# Vercel readiness checklist

Nothing here has been deployed. Items marked MANUAL need you.

## Already prepared in the repo
- Next.js 14 App Router, `next.config.mjs` with security headers (HSTS, nosniff, frame deny, referrer, permissions policy), `poweredByHeader` off.
- `postinstall` runs `prisma generate`, so Vercel's install step creates the Prisma client. `build` = `prisma generate && next build`.
- `engines.node >= 18.18`. Vercel's default Node is fine; Node 20 is what CI uses.
- Database migration `prisma/migrations/0001_init` is committed (hand-written from the schema, see STATUS: apply it to a throwaway database first).
- Admin routes are protected by middleware and re-checked in every page and server action. Cookie is httpOnly, SameSite=Strict, Secure in production.
- Secrets are read only on the server. Only `NEXT_PUBLIC_*` values reach the browser.

## MANUAL: environment variables (Vercel > Project > Settings > Environment Variables)
| Variable | Required | Notes |
|---|---|---|
| `DATABASE_URL` | yes | Postgres URL. On Neon use the pooled URL for the app. |
| `AUTH_SECRET` | yes | 32+ random characters (`openssl rand -base64 48`). Different per environment. |
| `NEXT_PUBLIC_SITE_URL` | yes | Final https URL, no trailing slash. Redeploy after changing. |
| `RESEND_API_KEY`, `EMAIL_FROM`, `LEAD_NOTIFY_EMAIL` | for email | Sender domain must be verified in Resend. Leads are saved even if email is not configured. |
| `NEXT_PUBLIC_CONTACT_EMAIL`, `NEXT_PUBLIC_LINKEDIN_URL`, `NEXT_PUBLIC_GITHUB_URL`, `NEXT_PUBLIC_BOOKING_URL` | no | Shown only if set. |
| `NEXT_PUBLIC_GA_ID` | no | Loaded only after visitor consent. |
| `NEXT_PUBLIC_LEGAL_REVIEWED` | no | Set `true` only after a lawyer has reviewed the legal pages. |

## MANUAL: database
1. Create a free Postgres database (Neon or Supabase).
2. Apply migrations from your computer using the DIRECT (non-pooled) connection string:
   `DATABASE_URL="<direct url>" npx prisma migrate deploy`
3. Create the first admin: `DATABASE_URL="<direct url>" ADMIN_EMAIL=you@company.com ADMIN_PASSWORD='long passphrase' npm run admin:create`

## MANUAL: after first deploy
- Submit a test quote: check it appears at `/admin` and that the email arrives.
- Confirm `/admin` redirects to sign-in when logged out, and `/robots.txt` + `/sitemap.xml` load.
- Add and verify the custom domain, then set `NEXT_PUBLIC_SITE_URL` and redeploy.
- Commit `package-lock.json` (generated by the first `npm install`) for reproducible installs.

## Known production gaps
- No strict Content-Security-Policy yet.
- Admin sessions are stateless (8 h); no per-session revocation, single role.
- Rate limiting is database-backed and not perfectly atomic under heavy concurrency.
- Vercel's free (Hobby) plan terms restrict commercial use. Check current terms before launching a business site on it.
